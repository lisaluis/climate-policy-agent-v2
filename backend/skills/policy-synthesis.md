# Skill: Evidence-Linked Policy Synthesis

## Synthesis procedure
1. Extract proposed actions from source passages; do not create facts that are not in the retrieved material.
2. Cluster near-duplicate actions using shared key terms.
3. Preserve citations from every source in each cluster.
4. Distinguish recurring themes from one-source suggestions.
5. Explain implementation questions that sources leave unanswered.
6. Where sources disagree, present the disagreement with citations instead of forcing consensus.
7. State that mention or repetition is not proof of policy effectiveness.
8. If there is insufficient evidence, return no recommendation rather than filling the gap with generic claims.
